# TypeScript 5.9, not 7

## Context

On npm, `typescript@latest` resolves to TypeScript 7 (the Go-based compiler). The repository must compile, lint and test reliably across Vitest, Drizzle, Zod, tsx and the Vercel AI SDK within a five-day deadline.

## Decision

Pin `typescript` to `~5.9.3` in every package. Do not use TypeScript 7 in this repository.

## Alternatives considered

- **TypeScript 7.** Faster, but ecosystem tooling (type plugins, editor integrations, `tsc` flags used by build configs) was not uniformly compatible at the time of the decision, and a surprise there costs a day we do not have.
- **Unpinned `^5`.** Would drift to 5.x patch releases only, but a tilde range makes the intent explicit to anyone reading `package.json`.

## Consequences

- Every package declares `"typescript": "~5.9.3"`; CI uses the lockfile, so the version is frozen.
- Revisit after the hackathon: moving to TypeScript 7 is a dependency bump plus a CI run, not a redesign.
